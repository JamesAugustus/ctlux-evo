# Evidence scope

These notes describe observations from saved DIALux evo 5.13 project files. The main derivation used one project. Selected photometry checks and result file header observations were repeated on a second project.

The observations support the documented record layouts and conversion steps within the limits in [METHOD.md](METHOD.md). They do not establish a complete file specification or numerical agreement with DIALux. Result illuminance values were not extracted.

Only saved project files were inspected using the ZIP format, ISO 10303-21 syntax, public Boost source code and general tools. The application was not decompiled or disassembled, and no protection measure was bypassed.

Public sources and overlapping work are credited in [RELATED_WORK.md](RELATED_WORK.md). This account does not claim independent proof of priority.
